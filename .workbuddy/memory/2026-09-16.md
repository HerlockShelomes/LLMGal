## 新教训

- **`git update-ref -d` 同样会触发删除保护**：清理旧中间分支 `wip/migrate-keep-on-reasoning` 时，
  `refs/heads/wip/` 整个目录被端掉（连带 `migrate-role-session`、`role-session-and-streaming`）。
  对象库无损。**恢复办法：用 Python 直接写 `.git/refs/heads/<name>` 文件内容为 `<sha>\n`**，别再用 git 命令。
- 结论更新：这个环境里 **任何带 `-d`/`--delete` 的 git 命令都不要用**，包括 `update-ref -d`、`branch -d`。
- `cmd /c` 从 PowerShell 工具调用会被安全策略拦截；PowerShell 管道捕获 git 输出会损坏内容
  （长文本只剩几行）。**统一改用 Python `subprocess` 调 git 并落盘**，字节级无损。
- `git ls-tree` 默认把中文路径转义成八进制，做路径比对要先 `-c core.quotePath=false`；
  比对文件内容还要统一 CRLF/LF（tar 导出会应用 `.gitattributes` 的 eol 转换）。
