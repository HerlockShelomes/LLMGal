# LLMGal 后端运行时依赖
# ---------------------------------------------------------------------------
# 本文件基于本机可运行的 vue-fastapi 虚拟环境（Python 3.11.13）整理，
# 仅保留后端代码实际 import 的第三方库（见 backend/*.py 的 import 清单），
# 并显式列出 volcengine 的其余运行时依赖。
#
# 已移除原 pip freeze 中约 80% 未被项目使用的包：
#   Flask / Jinja2 / Werkzeug / SQLAlchemy / mysqlclient / PyMySQL / redis /
#   redis-om / loguru / beautifulsoup4 / types-* / win32-setctime / websocat ...
#
# 关键坑（已在 tmp venv 实测复现并验证修复）：
#   volcengine==1.0.192 的元数据硬钉 pycryptodome==3.9.9，而 3.9.9 在
#   CPython 3.11 上没有预编译轮子，全新安装会尝试源码编译并需要 VC++ 14.0。
#   因此 pycryptodome 改为钉 3.21.0（有 cp311 的 abi3 轮子，实测可直接安装），
#   而 volcengine 由部署脚本以 `pip install --no-deps` 安装，避免被拉回 3.9.9。
#   => 不要把 volcengine 直接写进本文件再用 `pip install -r` 安装。
#
# 硬性约束：fastapi==0.95.1 + pydantic==1.10.7 在 Python 3.12 / 3.13 上
# 导入即报 TypeError（ForwardRef._evaluate 签名变更）。解释器必须锁定 3.11。
# 部署脚本 scripts/setup_env.sh 会自动校验 Python 版本。
# ---------------------------------------------------------------------------
